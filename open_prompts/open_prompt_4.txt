When you create a new project folder, here's what happens automatically:

---

## 🎯 **Step-by-Step Flow:**

### **1. You Create a New Project:**
```
Documents/
└── MyNewProject/
    ├── src/
    ├── README.md
    └── ... (your project files)
```

### **2. Monitor Auto-Detects It** (runs every 5 seconds)
The monitor sees your new folder and auto-initializes it.

### **3. Auto-Creates Folder Structure:**
```
MyNewProject/
├── .copilot-data/
│   ├── jira_stories/        ← JIRA chats go here
│   ├── open_prompts/        ← Open prompts go here
│   └── tokens_summary.json  ← Token tracking
├── src/
├── README.md
└── ...
```

### **4. You Copy Copilot Chat:**
- Open VS Code
- Ask Copilot something
- Copy the chat (Ctrl+A, Ctrl+C)

### **5. Monitor Detects & Saves:**

**If it has JIRA key** (like "JIRA-123: How to..."):
```
MyNewProject/.copilot-data/jira_stories/JIRA-123.txt
```
Contains:
```
====== JIRA-123 ======
Timestamp: 2026-08-21 10:45:33
Tokens: 245
Cost: $0.00294
Project: MyNewProject

User: JIRA-123 - How to implement...
Copilot: Here's how...
```

**If it's just a question** (no JIRA key):
```
MyNewProject/.copilot-data/open_prompts/2026-08-21_10-45-33.txt
```
Contains:
```
====== 2026-08-21 10:45:33 ======
Timestamp: 2026-08-21 10:45:33
Tokens: 156
Cost: $0.00187
Project: MyNewProject

User: How to optimize this...
Copilot: Try using...
```
